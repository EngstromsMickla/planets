# Planets

A small gravity game in the style of a celestial atlas. Fly a rocket
through moving gravity fields, slingshot past planets, leave the
system, or crash spectacularly. The wreckage stays in orbit.

Play: https://planets.mickla.se

## Privacy
Everything runs in your browser. Nothing is stored or sent, and there
are no cookies, external fonts or analytics. Sounds are synthesized
in the browser; there are no audio files.

## Built with
Plain HTML, CSS and JavaScript on a 2D canvas. Hosted on GitHub Pages.
